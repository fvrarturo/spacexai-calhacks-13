# SpaceXAI × Cal Hacks 13.0

Our Cal Hacks 13.0 project for the SpaceXAI **Make it Legendary** challenge.

## Brief

- **Use big data about space**: Earth observation, satellite imagery, mission archives, and the space literature.
- **Lead with the problem.** Pick a clear, real problem and a credible idea for solving it. The technical details matter less than the problem and the idea.

## Challenge rules (from the starter pack)

- The project must be built with **Cursor**. More Cursor use improves the odds of winning.
- Bonus points for using **Grok Bot** for project planning and team collaboration.
- Submit to the *Make it Legendary* challenge on **Devpost**.
- Prize: every member of the winning team gets a Cursor mechanical keyboard. Everyone who submits enters a raffle for a Cursor Owala water bottle.

The full starter pack is in [`docs/`](docs/).

The research for the idea is in [`research/`](research/00_INDEX.md). Start with [`research/12_idea_bank.md`](research/12_idea_bank.md), the ranked ideas with sponsor fit, data and demo plans. [`research/08-ideas.md`](research/08-ideas.md) is a second, shorter shortlist, and [`research/00-brief.md`](research/00-brief.md) has the challenge constraints. [`research/00_INDEX.md`](research/00_INDEX.md) lists every research file.
